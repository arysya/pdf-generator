# PDF-чек-мейкер

Программа на Python: берёт данные из CSV или JSON, подставляет их в HTML-шаблон
и собирает готовый PDF (чек, сертификат, акт). Есть два входа: окно с перетаскиванием файла
(`okno.py`) и консольное меню (`pdf_generator.py`). Домашнее задание урока VPa06 курса «Профессия вайб-кодер».

## Окно
Двойной щелчок по `zapusk.bat`. Перетащите таблицу в рамку (или нажмите на рамку и выберите файл).
Программа сама подберёт подходящий шаблон и скажет, сколько в таблице документов.
Кнопка «Собрать PDF» собирает все документы, полоска показывает ход работы,
в конце открывается папка `output` (или сам PDF, если он один).

## Что умеет
- Показывает меню: какие есть файлы с данными в `data/` и шаблоны в `templates/`.
- Даёт выбрать номер чека или собрать все сразу.
- Строки CSV с одинаковым `invoice_id` склеивает в один чек с несколькими позициями.
- Суммы и итог считает программа, а не шаблон.
- Кириллица работает: шрифт Golos Text лежит в `fonts/` и подключается к каждому PDF.
- Длинное название услуги переносится внутри ячейки и не ломает таблицу.
- Готовый PDF кладёт в `output/` и сразу открывает.
- Показывает только те шаблоны, которые подходят к выбранной таблице.

## Как запустить (Windows)
```
python -m venv venv
.\venv\Scripts\activate.ps1
pip install -r requirements.txt
python pdf_generator.py   # консольное меню
python okno.py            # окно
```
Для WeasyPrint на Windows нужен GTK3 Runtime:
https://github.com/tschoonj/GTK-for-Windows-Runtime-Environment-Installer/releases
(после установки перезапустить терминал).

На macOS: `brew install pango`, потом те же команды, активация через `source venv/bin/activate`.

## Файлы
| Файл | Что внутри |
|---|---|
| `pdf_generator.py` | вся работа с данными и PDF, консольное меню |
| `okno.py`, `zapusk.bat` | окно с перетаскиванием файла |
| `templates/chek.html` | чек спа-студии: клиент, мастер, таблица услуг, итог |
| `templates/sertifikat.html` | подарочный сертификат |
| `data/spa_cheki.csv` | 4 тестовых чека (8 строк) |
| `data/sertifikaty.json` | 3 тестовых сертификата |
| `primery/` | два готовых PDF: чек и сертификат |

Спа-студия «Тихая гавань» и все имена выдуманы для примера.

## Промпт, по которому собран проект
```
Напиши Python-скрипт, который:
1. Читает все доступные CSV и JSON файлы в директории /data.
   CSV — парсит модулем csv, JSON — стандартной библиотекой json.
   Строки CSV с одинаковым invoice_id собирай в один чек с несколькими позициями (product, qty, price).
2. Читает все HTML-шаблоны из директории /templates.
3. При запуске выводит пронумерованный список файлов с данными и шаблонов
   и даёт выбрать (через input) один файл данных и один шаблон.
4. Выводит список чеков (по invoice_id) из выбранного файла; можно выбрать один или все сразу.
5. Подставляет данные в шаблон (Jinja2, плейсхолдеры {{ product }}, {{ price }}, {{ qty }}),
   генерирует PDF через WeasyPrint и сохраняет в /output.
6. После генерации открывает PDF в системной программе.

Требования:
- Суммы по строкам и итог считай в Python через Decimal, формат «12 500,00».
- Кириллица: подключи шрифт из папки fonts через @font-face, файлы читай в UTF-8
  (CSV из Excel — с BOM, разделитель запятая или точка с запятой).
- Длинные строки в таблице переносятся внутри ячейки, таблица не разъезжается.
- Если в данных нет поля, которое ждёт шаблон, выведи понятную ошибку на русском.
- Работает на Windows и macOS. Аккуратное меню в консоли с нумерацией.
```
