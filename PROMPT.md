# Промпт, по которому собран проект

Домашнее задание урока VPa06 «Кейс: PDF-чек-мейкер» просит записать промпт. Вот он.

```
Напиши Python-скрипт, который:
1. Читает все доступные CSV и JSON файлы в директории /data.
   CSV — парсит модулем csv, JSON — стандартной библиотекой json.
   Строки CSV с одинаковым invoice_id собирай в один чек с несколькими позициями (product, qty, price).
2. Читает все HTML-шаблоны из директории /templates.
3. При запуске выводит пронумерованный список файлов с данными и шаблонов
   и даёт выбрать (через input) один файл данных и один шаблон.
4. Выводит список чеков (по invoice_id) из выбранного файла; можно выбрать один или все сразу.
5. Подставляет данные в шаблон (Jinja2, плейсхолдеры {{ product }}, {{ price }}, {{ qty }}),
   генерирует PDF через WeasyPrint и сохраняет в /output.
6. После генерации открывает PDF в системной программе.

Требования:
- Суммы по строкам и итог считай в Python через Decimal, формат «12 500,00».
- Кириллица: подключи шрифт из папки fonts через @font-face, файлы читай в UTF-8
  (CSV из Excel — с BOM, разделитель запятая или точка с запятой).
- Длинные строки в таблице переносятся внутри ячейки, таблица не разъезжается.
- Если в данных нет поля, которое ждёт шаблон, выведи понятную ошибку на русском.
- Работает на Windows и macOS. Аккуратное меню в консоли с нумерацией.
```

Второй шаг, окно с перетаскиванием файла:

```
Оберни генератор в окно на Tkinter: большая область «Перетащите сюда таблицу»
(tkinterdnd2) и кнопка выбора файла. После выбора файла программа сама подбирает
подходящий шаблон и пишет, сколько в таблице документов. Кнопка «Собрать PDF»
собирает все документы в фоне, полоска показывает ход работы, в конце открывается
папка с PDF. Любую ошибку показывай в окне по-русски: окно запускается без консоли.
```
